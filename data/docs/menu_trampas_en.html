Puerto Bravo Cheat Menu Manual

The cheat menu is an external Windows application with standard accessible controls designed for keyboard and screen-reader use while you play. It helps you test mods, move around the map, trigger specific situations, and adjust game values in real time without replaying missions. This guide is organized by headings: with your screen reader you can jump from section to section with the H key.

1. Requirements, activation, and language

  • Run MenuTrampas.exe, located next to PuertoBravo.exe.
  • For safety it is turned off by default: before any connection is opened, open Options, Combat and difficulty in the game and set Allow cheat menu to yes.
  • While that option is set to no, the game never opens a local port or creates the temporary link file, so the cheat menu will not detect any running session.

The window language is chosen when MenuTrampas.exe starts, in this priority order:

  1. The PUERTOBRAVO_IDIOMA environment variable, if set.
  2. The Language setting saved in the game configuration (data\config).
  3. If set to auto, your Windows (or system) language: if an installed catalog exists for that language it is used; otherwise English is used (and Spanish if English were unavailable).

If you change the language inside the game, close and reopen MenuTrampas.exe so the window reloads in the new language.

2. Connecting, syncing, and keyboard controls

Connection controls sit at the top of the window, followed by the tool tabs. When connecting and refreshing, the window reads the current game values (money, health, armor, wanted stars, hour, day, rain, nearby vehicles, and nearby people) so every field stays in sync.

  • Alt 1 (Game instance): list of active sessions detected on your computer.
  • Alt 2 (Connect / Disconnect): links to the selected instance. Once connected, the button label switches to Disconnect and refuses to open a duplicate connection; press it again to close the current link or reconnect later.
  • F5 or Alt 3 (Refresh): immediately resyncs overall status, editable fields, and entity lists.
  • Alt 4 and Alt 5: read-only boxes showing connection status and a quick player and world summary.
  • Control Tab and Control Shift Tab: switch between main tabs and sub-tabs.
  • Tab and Alt plus the underlined letter: move across controls or jump straight to a specific field or button.
  • Control H: speak the context help for the currently focused control through your screen reader.

See keys and buttons for the complete keyboard reference.

3. What it lets you do, tab by tab

Player

  • Combat & Status: adjust current health, max health, armor, concentration (focus), toggle invulnerable mode, or heal and restore everything.
  • Economy & Progress: edit cash on hand, bank balance, mood, neighborhood prestige, street reputation, license points, and bodyguards; add +5,000 or +50,000 euros, clear your criminal record, or unlock all properties.
  • Needs & Skills: adjust hunger, thirst, sleepiness, and dirtiness (or set all needs to 0), set any skill level (0 to 10), adjust practical cooking, or max out all skills.
  • Gang & Dog: edit gang name, boss alias, and members, call your gang, conquer the current neighborhood or all neighborhoods; adopt or call your dog and edit its name, hunger, and trust.

Inventory

  • Weapons: choose any weapon from the catalog, configure magazine, reserve ammo, silencer, and extended mag; give, equip, remove, or unlock all weapons.
  • Items & Backpack: set or add useful item quantities, place valuables in your backpack, enable the large backpack (40 slots), and clear stolen flags.
  • Substances & Food: set substance units (or add +10) and add food products to your pocket.

Vehicles

  • Spawn: spawn any vehicle model next to you, give it an optional custom name, mark it as yours, get in right away, and apply max upgrades.
  • Active Vehicles: list active vehicles in the current town and get in, bring here, repair, fill tank, fix breakdowns, apply max upgrades, make personal, explode, delete, or clear traffic.
  • Specs & Workshop: edit name, AI mode, max speed, acceleration, braking, current and max health, hostile or locked flags (this unit only or class-wide), and adjust specific workshop upgrades.

NPCs & Gangs

  • Spawn NPCs: spawn civilians, enemies, allies, or police by catalog class, gang, weapon, count, health, vehicle arrival, and hostile flag.
  • Active People: list people in the current area and edit name, health, accuracy, state, civilian trust, and current hostility; bring here, heal, kill, remove, clear hostiles, or clear fallen bodies.
  • Gang Reputation: check and set reputation with each gang (-100 to +100), or jump directly to allies (+100), neutral (0), or enemies (-100).

Police, Events, and World

  • Police: set current wanted stars (0 to 5), clear wanted status and chases, dispatch patrol cars or roaming patrols, launch or withdraw the helicopter, toggle no-police mode, and toggle level-5 police helicopter spawns.
  • Events: launch or cancel street events, start chases with a getaway vehicle model and target speed, start turf wars, pick fights, rob the nearby shop or bank, clear shop bans, call an ambulance, drop a 1,000 euro briefcase, or start contracts and car delivery jobs.
  • World: teleport to any town and place in the catalog (with text filtering), set hour, day, rain, and day type, or toggle quick gameplay rules (+18, friendly fire, street wars, realistic needs, fuel, breakdowns, traffic laws, drop weapons, tough enemies, and strict police).

Inspector

Allows safely reading and editing supported scopes of the save and settings (such as player, stats, config, current vehicle, or nearby person). Before applying the first Inspector change in a session, the bridge automatically creates a backup of your save at respaldo_antes_trampas.json inside your saves folder.

4. What it does not allow and safety limits

  • No gamepad support: because it is an external Windows window, it cannot be controlled with a controller; use keyboard and screen reader instead.
  • Closed game or disabled option: if PuertoBravo.exe is not running or Allow cheat menu is set to no, the bridge never starts and no commands can run.
  • Friends games and online servers: in co-op games with friends it is completely disabled. On an online dedicated server it only works if the owner enables permitir_trampas = si in the server config; otherwise communication stays blocked and all cheats are rejected. Keep in mind that when a server owner enables it, the server stops checking money changes for every player on that server (see the server guide).
  • Achievements disabled: as soon as you use any cheat in a solo save, that save is marked and achievements stop unlocking in that playthrough.
  • Inspector limits: it refuses arbitrary fields, internal attributes starting with _, and protected config keys (such as permitir_trampas, servidores, teclas, update URLs, or audio devices). It also strictly validates JSON syntax and field types: on any syntax or type error (for example single quotes, mismatched types, or out-of-range numbers), it reports the error clearly and modifies or adds nothing.
  • IPC bridge scope: listens on localhost only (127.0.0.1), requires a per-instance session token, and caps simultaneous connections (maximum 8) to prevent thread exhaustion.
